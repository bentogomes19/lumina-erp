## Prints dos manuais

`assets/manual/` guarda os prints dos manuais de uso, separados por portal (`admin/`, `professor/`, `aluno/`). Foram gerados em 24/10/2026 a partir da base de demonstração (seeders, dados sintéticos), com data do sistema fixada em 21/10/2026 e janela de 1440 px, e convertidos para WebP.

Nome dos arquivos: `NN-tela.webp`, na ordem do menu. Ao mudar uma tela, refaça o print com o mesmo nome para não quebrar os links.
