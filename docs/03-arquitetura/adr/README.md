# Registro de decisões de arquitetura (ADR)

Cada decisão técnica relevante ganha um arquivo `NNNN-titulo-curto.md` criado a partir do [template](../../_templates/adr.md). ADRs não são editadas depois de aceitas: quando a decisão muda, crie uma nova e marque a antiga como `substituida`.
